01 · Workspaces

Resume any Cursor workspace, instantly

Compass scans your machine for git repos and surfaces branch, PR, and comment activity — jump straight back into Cursor with the right folder already open. Spin up an isolated workspace and Compass creates a dedicated git worktree per repo, so you can run several Cursor sessions on different branches in parallel without any of them stepping on each other.

Instant resume Isolated worktrees Run in parallel

02 · Pull Requests

One-click actions on every PR

Right-click any PR to rebase on main and force-push, verify the title and description, address open review comments, or fix CI and monitor until it's green — all without leaving Compass, grouped by epic so you always know what's blocked and what's ready to ship.

Rebase & push Address comments Fix CI

03 · Projects

All your ongoing work, one canvas

Drag related PRs and repos into freeform groups, keep an eye on open counts and CI failures at a glance, and pick back up exactly where you left off — across every parallel Cursor workspace you've got running.

Canvas board Custom clusters At-a-glance status

04 · Agents

Every Cursor chat, searchable across every repo

Compass indexes your active and past Cursor agent sessions across all your projects, so you can jump back into any conversation without hunting through folders — pick up a chat from 40 minutes ago or 4 minutes ago just as easily.

Full chat history Cross-repo search Resume any session
